OverviewDNS sync

Point the cache-domains names at this cache on your own DNS server, instead of running lancache-dns.

DNS sync is off. Set DNS_SYNC_FILE (it defaults to /data/dns-sync.json) to turn it on.

Read-only. Set the DASHBOARD_PASSWORD environment variable to set up DNS sync from here.

Needed to save, sync or remove anything on this page.

What to publish

The addresses clients should reach this cache on, separated by spaces or commas. Each name gets one record per address.
Services

Unchecked services are left out, and records added for them earlier are removed at the next sync.

DNS servers

A sync adds the records that are missing and removes the ones it added earlier that are no longer wanted. It never touches records it did not add.
